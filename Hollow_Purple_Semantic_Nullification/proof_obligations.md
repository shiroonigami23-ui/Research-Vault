# Proof Obligations

## What We Can Defend Now

1. Antonyms and contradictions are nontrivial in embedding space.
2. Contradiction is a legitimate supervised semantic object.
3. Meaning-level uncertainty is a valid measurement target.
4. A nullification-style instability hypothesis is mathematically specifiable.

## What We Still Need to Prove

1. contradiction depth predicts instability beyond ambiguity alone,
2. a null-like regime appears reproducibly across models,
3. the effect is not only output-level but also representational,
4. the measured signal is not reducible to ordinary uncertainty.

## Minimal Formal Claims

### Claim H1

If contradiction depth increases, then average uncertainty increases.

### Claim H2

If contradiction depth increases, then repeated outputs diverge more.

### Claim H3

If contradiction depth increases, then hidden-state stability decreases.

## Falsification Conditions

- no significant difference from ambiguity controls,
- no monotonic trend with contradiction depth,
- no cross-model consistency,
- no internal signature beyond noisy text outputs.
