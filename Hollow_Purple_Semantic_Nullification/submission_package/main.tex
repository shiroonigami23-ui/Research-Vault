\begin{abstract}
This paper tests whether contradiction depth produces measurable instability in language models. We define semantic nullification as a contradiction-linked increase in uncertainty, semantic divergence, or representational instability relative to matched controls.
\end{abstract}

\section{Introduction}
This study treats contradiction as a controllable semantic stressor. The central question is whether increasing contradiction depth causes measurable instability beyond ambiguity alone.

\section{Mathematical Formulation}
Let $x$ denote a prompt, $M$ a language model, and $h_\ell(x)$ the hidden state of $x$ at layer $\ell$.

\subsection{Token Entropy}
For decoding step $t$, define
\[
H_t(x) = - \sum_i p_M(i \mid x, y_{<t}) \log p_M(i \mid x, y_{<t}).
\]
The average decoding entropy over $T$ steps is
\[
H_{\mathrm{avg}}(x) = \frac{1}{T} \sum_{t=1}^T H_t(x).
\]

\subsection{Hidden-State Drift}
Given a control prompt $x_c$ and contradiction prompt $x_k$, define
\[
D_\ell(x_c, x_k) = 1 - \cos\big(h_\ell(x_c), h_\ell(x_k)\big).
\]

\subsection{Semantic Variance}
Given repeated sampled outputs clustered into semantic groups with masses $q_j$, define
\[
SE(x) = -\sum_j q_j \log q_j.
\]

\subsection{Nullification Index}
We define a composite study index
\[
NI(x) = \alpha H_{\mathrm{avg}}(x) + \beta SE(x) + \gamma V_\ell(P_x) + \delta R(x),
\]
where $V_\ell(P_x)$ denotes paraphrase-level hidden-state variance and $R(x)$ denotes contradiction-resolution failure.

\section{Experimental Design}
We compare coherent controls, ambiguity controls, explicit contradictions, and deep contradictions using the benchmark in \texttt{benchmark\_suite.json}.

\section{Assumptions}
This study assumes that contradiction depth is experimentally manipulable, that hidden-state and uncertainty metrics are sensitive to contradiction-induced stress, and that matched ambiguity controls can separate contradiction effects from generic prompt difficulty.

\section{Formal Claim Structure}

\subsection{Definition}
Semantic nullification is the condition in which contradiction-bearing prompts exhibit measurable instability relative to matched controls in uncertainty, semantic divergence, or representational stability.

\subsection{Proposition H1}
Increasing contradiction depth increases average uncertainty.

\subsection{Test Statistic for H1}
Compare condition-wise means of $H_{\mathrm{avg}}(x)$ across contradiction levels and ambiguity controls.

\subsection{Decision Rule for H1}
Support H1 only if contradiction conditions show a stable directional increase in $H_{\mathrm{avg}}(x)$ beyond matched ambiguity controls across repeated runs.

\subsection{Null Hypothesis for H1}
Contradiction depth has no effect on average uncertainty beyond ordinary ambiguity or prompt difficulty.

\subsection{Effect-Size Target for H1}
The target is a consistent positive shift in average uncertainty large enough to remain visible across paraphrases, repeated runs, and at least one additional model family.

\subsection{Control Condition for H1}
Use length-matched ambiguity prompts and semantically rich but non-contradictory prompts as controls.

\subsection{Confound Checklist for H1}
\begin{itemize}[leftmargin=*]
\item prompt length imbalance,
\item decoding-temperature artifacts,
\item rare-token effects,
\item generic ambiguity rather than contradiction.
\end{itemize}

\subsection{Failure Mode for H1}
H1 fails if uncertainty rises equally under non-contradictory ambiguity, or if no monotonic trend appears with contradiction depth.

\subsection{Proposition H2}
Increasing contradiction depth increases semantic output divergence.

\subsection{Test Statistic for H2}
Compute semantic entropy $SE(x)$ or repeated-output cluster dispersion for each condition.

\subsection{Decision Rule for H2}
Support H2 only if contradiction conditions produce consistently higher semantic divergence than controls under fixed decoding settings.

\subsection{Null Hypothesis for H2}
Contradiction depth does not increase semantic divergence beyond baseline decoding variability.

\subsection{Effect-Size Target for H2}
The target is a repeatable increase in semantic cluster entropy relative to both coherent and ambiguity controls.

\subsection{Control Condition for H2}
Compare against coherent prompts and ambiguity prompts with similar lexical complexity and output length.

\subsection{Confound Checklist for H2}
\begin{itemize}[leftmargin=*]
\item stochastic decoding variance,
\item paraphrase-clustering instability,
\item evaluator inconsistency,
\item uncontrolled topic shifts across prompt families.
\end{itemize}

\subsection{Failure Mode for H2}
H2 fails if repeated outputs remain as stable as control outputs or if divergence is explained entirely by decoding randomness.

\subsection{Proposition H3}
Increasing contradiction depth decreases representational stability.

\subsection{Test Statistic for H3}
Measure $D_\ell(x_c,x_k)$ and within-family hidden-state variance $V_\ell(P_x)$ across layers.

\subsection{Decision Rule for H3}
Support H3 only if contradiction families show persistently larger drift or variance than coherent controls across relevant layers.

\subsection{Null Hypothesis for H3}
Contradiction depth does not alter hidden-state stability beyond normal contextual variation.

\subsection{Effect-Size Target for H3}
The target is a layerwise instability pattern that appears consistently enough to separate contradiction families from controls.

\subsection{Control Condition for H3}
Use coherent and ambiguity controls matched on length, syntax, and entity structure.

\subsection{Confound Checklist for H3}
\begin{itemize}[leftmargin=*]
\item token-position effects,
\item model-specific activation scaling,
\item prompt formatting artifacts,
\item layer selection bias.
\end{itemize}

\subsection{Failure Mode for H3}
H3 fails if internal geometry remains indistinguishable from controls or if instability is confined to output text alone.

\section{Validation}
The theory is supported only if contradiction depth predicts instability beyond ambiguity controls across more than one metric.

\section{Related Work}
This study sits at the intersection of lexical contrast in embeddings, contradiction-sensitive language understanding, and uncertainty measurement in language models. The contribution here is narrower and more operational: contradiction depth is treated as the primary manipulated variable, and instability is defined through explicit statistics rather than metaphor alone.

\section{Falsifiers}
The theory is weakened if contradiction prompts fail to separate from ambiguity controls, if no monotonic relationship appears across contradiction depth, or if the effect vanishes across models and paraphrases.

\section{Evidence and Proof Standard}
Evidence means stable separation under controls. Strong evidence requires replication across paraphrases, metrics, and models. Proof, in the empirical sense, requires that no simpler explanation survives within scope.

\section{Conclusion}
Semantic nullification is not yet proven, but it is now operationally defined and empirically testable.
