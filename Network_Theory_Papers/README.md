# Network Theory Papers

This folder groups two manuscript rebuilds derived from source PDFs:

- `network-theory-papers/neuro-spike-net`
- `network-theory-papers/sparse-net`

Each paper folder contains:

- `source.pdf` — original provided PDF
- `extracted_text.txt` — PDF text extraction for reconstruction
- `paper/main.tex` — compile-ready LaTeX manuscript
- `paper/references.bib` — bibliography
- `paper/figures/` — extracted figures from the source PDF

Final exported PDFs and DOCX files can later be copied into `Research_Papers/`.
