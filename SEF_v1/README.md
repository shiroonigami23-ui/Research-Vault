# SEF v1

Root-level publication package for the Spectral Entropy-Fold (SEF) hypothesis paper.

## Structure
- `submission_package/`: Springer-style LaTeX source, bibliography, and compile assets.
- `SEF_v1_Aryan_Singh_Chandel.pdf`: latest compiled PDF export.
- `SEF_v1_Aryan_Singh_Chandel.docx`: latest editable manuscript export.

## Scope
This package upgrades the earlier `Research_Papers/SEF_v1` artifacts into a journal-style manuscript with stronger mathematical framing, diagrams, tables, and an explicit validation/falsification program.
