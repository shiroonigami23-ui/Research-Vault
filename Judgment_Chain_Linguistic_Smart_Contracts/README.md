# Judgment Chain Linguistic Smart Contracts

Research study inspired by Kurapika's "Judgment Chain" and mapped to hard linguistic constraint systems for AI safety.

## Focus
- constitutional rules vs hard guardrails
- prompt jailbreak resistance
- symbolic enforcement over natural-language policies

## First Questions
1. Why do prompt-only rules fail?
2. What constraints must be externalized to become unbreakable?
3. Can we model policy rules as linguistic smart contracts?
