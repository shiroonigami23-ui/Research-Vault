# Alluka Something Algorithmic Debt

Research study inspired by Alluka's wish system and mapped to prompt complexity, token economics, and AI safety overhead.

## Focus
- prompt complexity beyond token count
- scaling of validation and safety cost
- sequential overhead after large or ambitious requests

## First Questions
1. How should prompt burden be measured?
2. Does safety overhead scale nonlinearly with task ambition?
3. Can we formalize a Something-Alluka Index?

## Working Files
- `review_paper_v1.md` - first review-style theory paper
- `evidence_validation_notes.md` - proof boundaries and validation plan
- `related_work_notes.md` - literature map for the study
