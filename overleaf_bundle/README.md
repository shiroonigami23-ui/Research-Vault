# Overleaf Bundle

This folder contains upload-ready LaTeX paper packages.

## Contents

- `hollow_purple_semantic_nullification/`
- `judgment_chain_linguistic_smart_contracts/`
- `alluka_something_algorithmic_debt/`

Each paper folder contains:

- `main.tex`
- `references.bib`

## Usage

1. Open or create a project in Overleaf.
2. Upload one paper folder's contents into that project.
3. Set `main.tex` as the main file if needed.
4. Recompile.

## Notes

- These are local mirror copies of the tracked paper drafts.
- If the source paper changes, regenerate this bundle.
