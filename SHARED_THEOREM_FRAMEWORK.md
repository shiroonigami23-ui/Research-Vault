# Minimal Research Standard

This file is intentionally minimal.

The three active studies in this repository are theory-distinct and should be read primarily through their own local definitions, propositions, metrics, and falsifiers.

## Repo-Wide Rules

1. State assumptions explicitly.
2. Distinguish evidence from proof.
3. Define at least one real falsifier for each main claim.
4. Avoid overgeneralizing beyond the tested scope.
5. Prefer study-local rigor over shared abstraction.

## Where the Real Framework Lives

- `Hollow_Purple_Semantic_Nullification/`
- `Judgment_Chain_Linguistic_Smart_Contracts/`
- `Alluka_Something_Algorithmic_Debt/`

Each study contains its own:

- definitions,
- propositions,
- test statistics,
- decision rules,
- null hypotheses,
- controls,
- confound checklists,
- and failure modes.
